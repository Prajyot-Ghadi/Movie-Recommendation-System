🎬 Movie Recommendation System

A content-based movie recommender system built using Python and Streamlit.
The system recommends movies similar to the one selected by the user based on feature similarity.

Project Overview

This project uses content-based filtering to recommend movies.
Movie similarity is calculated using vectorized features and a similarity matrix.
A simple Streamlit web interface allows users to select a movie and view recommendations.


Features

Recommends movies based on similarity

Simple and interactive web interface

Built using Python and Streamlit

No external API dependency

Suitable for academic and demo purposes



Technologies Used

Python

Streamlit

Pandas

Scikit-learn

Pickle

Jupyter Notebook

How the System Works

Movie data is preprocessed in a Jupyter Notebook

Important features are vectorized

A similarity matrix is computed

For a selected movie, the most similar movies are identified

Recommended movie names are displayed to the user
